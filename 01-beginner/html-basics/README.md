# 🟢 Beginner Level - HTML Basics

**10 Fundamental HTML Programs**

Learn the basics of HTML structure, semantic elements, and content organization.

## Programs

1. **Personal Profile** - Profile card with contact information
2. **Blog Layout** - Complete blog structure with articles
3. **Image Gallery** - Grid-based photo gallery
4. **Contact Form** - Professional contact form
5. **Data Table** - Styled data table
6. **Navigation Menu** - Multi-level navigation
7. **Semantic Page** - HTML5 semantic structure
8. **Media Page** - Video and audio embedding
9. **List Layouts** - Various list styles
10. **HTML5 Showcase** - Modern HTML5 elements

## Learning Objectives

- HTML document structure
- Semantic HTML5 elements
- Forms and inputs
- Tables and lists
- Media embedding
- Accessibility basics
