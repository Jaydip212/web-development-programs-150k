# Personal Profile Page

**Level:** Beginner  
**Category:** HTML Basics  
**Created by:** Jayvik Labs - Jaydip

## 📝 Description

A beautiful personal profile card showcasing basic HTML structure with modern CSS styling. Features a gradient background, profile image placeholder, contact information, and social media links.

## ✨ Features

- Clean and modern card design
- Gradient backgrounds
- Profile information display
- Social media links
- Smooth animations
- Responsive layout

## 🎯 Learning Objectives

- HTML document structure
- Semantic HTML elements
- CSS styling basics
- Flexbox layout
- CSS animations
- Gradient backgrounds

## 🚀 How to Use

1. Open `index.html` in your web browser
2. View the profile card with all information
3. Hover over social media buttons to see effects

## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox
- CSS Animations

## 📚 Key Concepts

- **HTML Structure**: Proper document setup with head and body
- **CSS Styling**: Modern styling with gradients and shadows
- **Layout**: Centered card layout using Flexbox
- **Animations**: Smooth slide-up animation on load
- **Hover Effects**: Interactive button transformations

## 🎨 Customization

You can customize:
- Profile name and title
- Contact information
- Profile image (replace with actual image)
- Color scheme (modify gradient colors)
- Social media links

## 💡 Tips

- This is a static HTML page with inline CSS
- Perfect for learning HTML/CSS basics
- Can be extended with JavaScript for interactivity
- Use as a template for your own profile
